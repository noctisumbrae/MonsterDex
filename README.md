# MonsterDex

Projeto acadêmico em React que funciona como um catálogo simples de Pokémon usando a PokéAPI.

## Funcionalidades

- Catálogo paginado com 30 Pokémon por página
- Busca por nome ou número
- Filtro por jogo em formato de tags
- Filtro por tipo com select
- Ordenação por número ou nome
- Página de detalhes para cada Pokémon
- Footer com disclaimer de uso acadêmico

## Tecnologias

- React
- React Router DOM
- JavaScript
- CSS comum
- PokéAPI

## Como executar

Instale as dependências:

```bash
npm install
```

Rode o projeto:

```bash
npm start
```

Depois acesse:

```txt
http://localhost:3000
```

## Observação

Este projeto usa Create React App, seguindo um padrão simples de aula, sem Vite, Next.js, TypeScript, Redux ou bibliotecas avançadas de estado.
